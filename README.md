# 灵境 · 指间幻境

用 **手势、表情、身体** 驱动的 AR 互动艺术网页。打开摄像头，在空气里捏出霓虹方盒、划碎屏幕、画心星爆、托起花之立方；也可以敲木鱼、颂钵、泡茶、插花、抽节气签、玩体感小游戏、AR 换装、搓黑胶、玩复古录音机。

- 在线体验：https://xiangshu3721.github.io/lingjing/
- 所有画面、声音只在本机处理，不上传；没有后端、没有统计、没有海外 CDN。
- 没有摄像头 / 拒绝权限也能用手指或鼠标玩（每个场景都有触屏玩法）。

| 场景 | 玩法 | 输入 |

## 技术

- React + TypeScript + Vite；Three.js（3D/粒子/着色器）+ Canvas2D；WebAudio 实时合成全部声音与音乐。
- MediaPipe tasks-vision 0.10.35：HandLandmarker / FaceLandmarker（含 blendshapes）/ PoseLandmarker lite。
  模型与 wasm 全部放在本站 `public/models`、`public/wasm`（由 `scripts/copy-wasm.mjs` 从 npm 包拷贝），按场景懒加载，存入 Cache Storage，第二次秒开。
- GPU 优先（超时/出错自动回退 CPU，iOS 直接 CPU）；识别节流自适应；离开场景关闭摄像头、释放 WebGL。
- 目录：`src/engine`（摄像头、识别池、手势识别、坐标映射、输入统一、音频）、`src/scenes/<场景>`、`src/hall`、`src/ui`。

## 开发

```bash
npm install
npm run dev        # 本地开发
npm test           # 单元测试（手势识别、坐标映射、碎片切分、WAV 编码）
npm run build && npm run preview
python3 e2e/e2e.py http://localhost:4174/lingjing/      # 端到端（假摄像头 + 无摄像头）
python3 e2e/gestures.py http://localhost:4174/lingjing/ # 合成手势验证四个复刻场景
npm run deploy:gh  # 发布到 GitHub Pages（gh-pages 分支）
```
